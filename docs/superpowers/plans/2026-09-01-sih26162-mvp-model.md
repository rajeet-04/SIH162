# SIH26162 MVP and Model Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a reproducible, leakage-safe SIH26162 MVP that classifies thermal events with a two-stage calibrated model, verifies selected events with satellite imagery, and presents risk and evidence in an offline-capable geospatial dashboard.

**Architecture:** A Python pipeline inventories immutable external data, creates canonical event and image manifests, produces time-safe features and provenance-aware labels, and trains calibrated hierarchical CatBoost models plus an optional PyTorch image verifier. A FastAPI service exposes predictions and evidence to a Bun-managed React/MapLibre client; frozen Parquet and image fixtures keep the full judge journey available offline.

**Tech Stack:** Python 3.12, uv, pandas, PyArrow, Pydantic 2, Pandera, scikit-learn, CatBoost, PyTorch, Rasterio/Xarray/H5Py, FastAPI, pytest, Bun, React, TypeScript, Vite, MapLibre GL JS, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-01-sih26162-mvp-model-design.md`

## Global Constraints

- Raw files under `D:\data`, `R:\MiCASA_FLUX*`, and `D:\MCD64A1` are immutable inputs; generated artifacts live under the repository's `data/`, `models/`, or `reports/` directories.
- Global Fire Atlas ignition and perimeter records are joined by year plus `fire_ID`; they are not stacked as independent fires, and its 2003-2016 coverage is historical supervision rather than the sole modern ranking population.
- The newest chronological 10% is the untouched final ranking set; all tuning, preprocessing, calibration, and threshold selection use only the older 90%.
- Source scenes, acquisitions, and tight location/facility groups cannot cross split boundaries.
- Historical features use only observations strictly earlier than the prediction timestamp.
- The tabular hierarchical model is the decision engine; image evidence cannot silently override it.
- Model disagreement or out-of-distribution evidence returns `uncertain / review required`.
- Promotion requires industrial-fire recall at least 85%, macro F1 at least 0.75, persistent-source false-alert rate at most 15%, no severe segment collapse, and CPU inference below one second per event.
- The MVP must complete its primary demo journey without network access.
- GPU training must fit an NVIDIA GeForce RTX 5050 with approximately 8 GB VRAM; production inference must run on CPU.

```python
# src/thermis/inventory.py
from hashlib import blake2b
from pathlib import Path

import pandas as pd


def fast_hash(path: Path, chunk_size: int = 1024 * 1024) -> str:
    digest = blake2b(digest_size=16)
    with path.open("rb") as handle:
        first = handle.read(chunk_size)
        digest.update(first)
        if path.stat().st_size > chunk_size:
            handle.seek(max(0, path.stat().st_size - chunk_size))
            digest.update(handle.read(chunk_size))
    digest.update(str(path.stat().st_size).encode())
    return digest.hexdigest()


def inventory_root(root: Path, source_family: str) -> pd.DataFrame:
    rows: list[dict[str, object]] = []
    for path in sorted(item for item in root.rglob("*") if item.is_file()):
        excluded = path.suffix.lower() in {".part", ".tmp", ".crdownload"}
        rows.append(
            {
                "path": str(path),
                "source_family": source_family,
                "extension": path.suffix.lower(),
                "size_bytes": path.stat().st_size,
                "modified_utc": pd.Timestamp(path.stat().st_mtime, unit="s", tz="UTC"),
                "fast_hash": fast_hash(path),
                "status": "excluded" if excluded else "candidate",
                "exclusion_reason": "incomplete_download" if excluded else None,
            }
        )
    return pd.DataFrame(rows)
```
